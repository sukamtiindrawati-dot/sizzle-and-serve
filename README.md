Sizzle & Serve — an original Indonesian street-kitchen cooking game. Pick ingredients, chop & cook, plate the dish, serve it fast before orders expire. Five recipes (Nasi Goreng, Mie Goreng, Sate Plate, Omelette Rice, Veggie Stir-Fry), a 150-second day, combo scoring, and a reputation that drops when an order expires.

## Run it

```sh
node serve.ts
```

Then open the game in a desktop browser (or open `game/index.html` directly). Controls: WASD / arrows to move, E to interact (hold to chop or cook), Space to start, P to pause, R to restart. Mouse: click to move, click a station to interact.
